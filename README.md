# Dijkstra Graph Solver

Interactive web app untuk visualisasi shortest path menggunakan algoritma Dijkstra.

## Features

- Tambah node dengan klik pada board
- Drag node untuk ubah posisi
- Hubungkan node dengan edge berbobot
- Visualisasi shortest path otomatis

## Installation

```bash
git clone https://github.com/username/repository-name.git
cd repository-name

npm install
```

## Environment

`.env.local`

```env
NEXT_PUBLIC_BACKEND_URL=http://localhost:8000
```

## Run

```bash
npm run dev
```

Buka `http://localhost:3000` di browser.
